## The loop

1. `am gen` — compile the spec, regenerate `gen/`, migrations, clients and this file.
2. `am check` — build, vet and run the Ambit analyzers; fix every finding.
3. `am test` — generated policy tests plus yours, against a real Postgres.
4. `am migrate plan` — see what the schema change costs before applying it.
5. `am diff --base main` — the behaviour change a human reviews.
